# PaiAgent Studio 用户说明手册

> 适用版本：1.0.0  
> 更新日期：2026-10-19  
> 适用对象：首次使用 PaiAgent Studio 的本地用户与内网演示人员。  
> 相关文档：[设计文档](design.md) · [项目总结](project-summary.md) · [阶段总结](phase-summary.md)

## 一、产品简介

PaiAgent Studio 是一个 AI 播客工作流工作室。你可以在画布上编排节点，输入一段文字进行调试，实时查看每个节点的执行过程，最终得到一段可播放、可下载的 MP3 播客。

默认工作流：

```text
用户输入 → 大模型 → 超拟人音频合成 → 结束
```

两种运行模式：

| 模式 | 条件 | 表现 |
| --- | --- | --- |
| 本地口播整理 | 未配置大模型密钥 | 调试抽屉显示 `LOCAL SCRIPT`，链路仍可完整生成音频 |
| 真实大模型 | 在 `backend/.env` 配置密钥 | 调试抽屉显示 `LIVE MODEL`，由所选模型生成口播稿 |

> 音频合成由在线 Edge Neural TTS 完成，需要网络连接，但不需要密钥。

## 二、运行前准备

### 2.1 环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10/11（一键脚本）；其他系统可手动启动 |
| Python | 3.12 或更高版本 |
| Node.js | 20 或更高版本 |
| 浏览器 | 最新版 Chrome、Edge 或其他现代浏览器 |
| 网络 | 合成音频时需要访问 Edge TTS；接入真实大模型时需要访问对应 API |
| 大模型密钥 | 可选。不配置也可使用本地口播整理模式 |

项目无需单独安装数据库。SQLite 数据库会在首次启动时自动创建。

### 2.2 Windows 一键安装

在项目根目录双击 `setup.bat`，或在命令行执行：

```bat
setup.bat
```

脚本会完成：

1. 检测 Node.js 20+ 与 Python 3.12+。
2. 创建 `backend\.venv` 虚拟环境并安装后端依赖。
3. 如果不存在 `backend\.env`，从 `.env.example` 复制一份。
4. 安装前端依赖。
5. 运行后端单元测试。

看到 `Setup complete` 表示安装完成。若提示缺少运行时，请先安装 Python 或 Node.js 后重新执行。

### 2.3 启动与访问

双击 `start.bat`，或在命令行执行：

```bat
start.bat
```

脚本会打开两个服务窗口并自动打开浏览器。

| 服务 | 地址 | 说明 |
| --- | --- | --- |
| 工作室 | <http://127.0.0.1:5180> | 日常使用入口 |
| 后端 API | <http://127.0.0.1:8010> | 接口服务 |
| API 文档 | <http://127.0.0.1:8010/docs> | FastAPI 交互式文档 |

停止服务时，关闭两个服务窗口即可。

### 2.4 手动启动

后端：

```bat
cd backend
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
copy .env.example .env
.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8010
```

前端：

```bat
cd frontend
npm install
npm run dev
```

macOS 或 Linux 下，将 Python 虚拟环境路径替换为 `.venv/bin/python`，并使用 `cp` 代替 `copy`。

## 三、界面导览

![PaiAgent Studio 界面](preview.png)

| 区域 | 位置 | 用途 |
| --- | --- | --- |
| 顶栏 | 页面顶部 | 修改工作流名称、查看引擎状态与保存状态、保存、重置、打开/收起调试 |
| 节点库 | 左侧 | 查看并添加用户输入、结束、大模型、超拟人音频合成节点 |
| 画布 | 中部 | 拖拽节点、连接端口、调整位置、缩放与平移 |
| 节点检查器 | 右侧 | 未选中节点时查看工作流概览；选中节点后编辑该节点配置 |
| 调试抽屉 | 底部 | 输入测试文字、运行工作流、查看执行轨迹与生成结果 |

顶栏中部会显示：

- **DAG 引擎在线**：后端连接正常。
- **引擎离线**：后端未启动或连接失败，需要检查服务。
- **有未保存更改 / 已保存时间**：提示当前文档的保存状态。

## 四、快速上手

使用默认工作流完成第一次播客生成：

1. 启动项目并打开 <http://127.0.0.1:5180>。
2. 确认顶栏显示“DAG 引擎在线”。
3. 调试抽屉默认已打开，在“测试输入”中输入一个主题，或点击“夜晚与播客”等示例话题。
4. 点击“运行工作流”，或按 `Ctrl/Cmd + Enter`。
5. 观察画布与执行轨迹：节点会依次变为运行中、成功，连线同步高亮。
6. 等待音频合成完成，在“生成结果”中点击播放按钮试听。
7. 展开“查看完整口播稿”可查看最终文本。
8. 点击顶栏“保存”，将当前工作流写入本地后台。

首次合成 60 秒左右的音频通常需要十余秒。未配置密钥时，调试抽屉右上角显示 `LOCAL SCRIPT`，这是正常现象。

## 五、编辑工作流

### 5.1 添加节点

有两种方式：

- **点击添加**：在左侧节点库点击节点卡片，节点会自动放到当前可视区域的空白位置。
- **拖拽添加**：按住节点卡片拖入画布，在目标位置松开。

规则：

- 用户输入和结束节点是边界节点，画布中最多各一个。
- 大模型与超拟人音频合成节点可以添加多个，组成更长的处理链。
- 自动放置会避开已有节点；若画布过小，则放在可视区域中央附近。
- 工作流运行期间不能添加、删除或拖拽节点。

### 5.2 连接节点

1. 将鼠标移到上游节点右侧的连接圆点。
2. 按住并拖到下游节点左侧的连接点。
3. 松开后生成带箭头的连线。

连线规则：

- 结束节点不能再向下游连线。
- 用户输入节点不能接收上游连线。
- 节点不能连接自身。
- 不允许重复连接同一对节点。
- 不允许形成循环依赖。

连线定义执行顺序，而不是节点在画布上的左右位置。若节点未接入“用户输入 → 结束”主链路，运行时会收到中文提示。

### 5.3 选中与配置

点击节点后，右侧检查器会切换到该节点的设置。点击画布空白处或检查器右上角的关闭按钮，可返回工作流概览。

边界节点说明：

- **用户输入**：内容是每次运行时来自调试抽屉的测试文字，不在节点中固定。
- **结束**：汇总主链路文本、音频与音色说明，不可删除。

### 5.4 删除节点

- 选中普通节点后，在检查器底部点击“删除这个节点”。
- 也可以选中节点或连线后按 `Delete` 或 `Backspace`。
- 删除节点会同时移除相关连线。
- 用户输入与结束节点不可删除。
- 运行期间不可删除。

### 5.5 保存、恢复与重置

| 操作 | 方式 | 说明 |
| --- | --- | --- |
| 重命名工作流 | 顶栏名称输入框 | 最多 48 个字符，回车确认输入 |
| 保存 | 顶栏“保存”或 `Ctrl/Cmd + S` | 写入后端 SQLite |
| 恢复 | 刷新页面 | 自动加载最近一次已保存的工作流 |
| 重置 | 顶栏重置图标 | 恢复内置示例链路，未保存修改会丢失 |

注意：刷新页面只恢复**已保存**版本。未保存的修改会丢失。重置操作会先弹出确认框。

### 5.6 运行前的合法性要求

工作流必须满足以下条件才能执行：

1. 有且仅有一个用户输入节点。
2. 有且仅有一个结束节点。
3. 所有节点都能从用户输入到达，并且都能到达结束节点。
4. 不存在循环连线。
5. 不存在自连、重复连线或指向不存在节点的连线。
6. 节点与连线数量不超过后端限制（60 个节点、120 条连线）。

调试输入不能为空。建议从“用户输入”开始，沿单一主链路依次连接到大模型、语音合成和结束节点。

## 六、节点配置详解

### 6.1 节点类型总览

| 节点 | 作用 | 主要配置 |
| --- | --- | --- |
| 用户输入 | 接收调试抽屉中的测试文字，作为流程起点 | 节点名称 |
| 大模型 | 将主题或草稿改写为可朗读的口播稿 | 模型名称、温度、系统提示词 |
| 超拟人音频合成 | 将上游文本合成为 MP3 音频 | 中文音色、语速、音调 |
| 结束 | 汇总文本与最新音频，送入调试结果区 | 无额外配置 |

所有节点都可以在检查器的“基础”区域修改节点名称，最多 40 个字符。

### 6.2 大模型节点

| 设置 | 范围 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 模型名称 | 文本 | `gpt-4o-mini` | 可输入大模型服务支持的模型名 |
| 温度 | 0 ～ 1.5 | 0.7 | 越低越稳定，越高越发散 |
| 播客编剧提示词 | 最多 4000 字 | 内置播客提示词 | 可点击“恢复默认”还原 |

关于模型名称：

- 节点内填写的模型名优先于 `backend/.env` 中的 `LLM_MODEL`。
- 未配置密钥时，模型、温度和提示词设置不会参与本地口播整理。

默认提示词要求模型输出 220～360 个汉字、口语化、无标题、无分点、无 Markdown，适合直接朗读。

### 6.3 超拟人音频合成节点

可用音色：

| 音色 | 性别 | 风格 | 音色 ID |
| --- | --- | --- | --- |
| 晓晓 | 女声 | 温暖自然 | `zh-CN-XiaoxiaoNeural` |
| 晓伊 | 女声 | 清晰明快 | `zh-CN-XiaoyiNeural` |
| 晓辰 | 女声 | 亲切闲聊 | `zh-CN-XiaochenNeural` |
| 晓涵 | 女声 | 知性温和 | `zh-CN-XiaohanNeural` |
| 云希 | 男声 | 年轻活力 | `zh-CN-YunxiNeural` |
| 云健 | 男声 | 沉稳磁性 | `zh-CN-YunjianNeural` |
| 云扬 | 男声 | 新闻播音 | `zh-CN-YunyangNeural` |
| 云夏 | 男声 | 清朗少年 | `zh-CN-YunxiaNeural` |

声音参数：

| 参数 | 范围 | 步长 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 语速 | -30% ～ +30% | 5% | 0% | 负值更舒缓，正值更明快 |
| 音调 | -50 ～ +50 Hz | 5 Hz | 0 Hz | 负值更低沉，正值更明亮 |

其他规则：

- 上游进入语音节点的文本最多 3000 字，超出会报错，需缩短口播稿。
- 音频合成需要联网，首次生成会等待一段网络请求。
- 每次成功合成都会生成新的 MP3 文件，不会覆盖旧文件。

### 6.4 结束节点

结束节点会汇总主链路上的口播稿和最近一段音频，最终结果展示在调试抽屉的播放器中。该节点没有可编辑参数，也不能删除。

## 七、调试与生成

### 7.1 输入测试文字

- 调试抽屉打开时会自动聚焦输入框。
- 输入上限为 4000 字，输入框右下角显示当前字数。
- 可点击“夜晚与播客”“给紧张的人”“工具的意义”快速填入示例。
- 测试文字会自动保存在浏览器本地，刷新页面后仍会保留。
- 输入为空时“运行工作流”按钮不可用。

调试抽屉右上角的模式标签：

- `LOCAL SCRIPT`：本地口播整理模式。
- `LIVE MODEL`：已配置大模型，将调用在线模型。

### 7.2 运行与停止

点击“运行工作流”开始执行。运行时：

- 按钮变为“正在生成播客”。
- 顶栏显示“正在执行”。
- 画布顶部显示执行进度与 `LIVE` 标识。
- 调试抽屉显示“已完成 x/y”。

需要中止时点击“停止”。停止会立即中止前端等待并提示“已停止本次运行”，但服务端已经发出的外部请求可能仍会短暂完成。

### 7.3 查看执行轨迹

执行轨迹按节点展示：

| 信息 | 说明 |
| --- | --- |
| 状态 | 运行中、成功、失败 |
| 耗时 | 节点成功后的执行时间 |
| 提供方 | 用户输入、大模型、本地整理、神经语音、结束输出 |
| 文本 | 完成节点的输出预览 |
| 错误 | 失败节点的中文错误原因 |

节点失败会立即中断后续节点，已成功节点的记录仍会保留。画布上的节点和连线会同步显示当前运行状态。

### 7.4 查看生成结果

运行成功后，结果区提供：

- 播客播放器与音色说明。
- “查看完整口播稿”折叠区。
- 下载音频入口。
- 无音频或部分节点失败时的提示。

若工作流没有产出音频，结束节点仍可能返回文本，同时附带警告信息。

## 八、音频播放与下载

播放器支持：

- 点击圆形按钮播放或暂停。
- 查看当前时间与总时长。
- 拖动进度条跳转位置。
- 点击右下角下载按钮，保存为 `paiagent-podcast.mp3`。
- 波形会随播放进度点亮。

如果浏览器拦截自动播放，点击一次播放按钮即可。音频加载失败时，请重新运行工作流或检查后端服务。

## 九、接入真实大模型

### 9.1 配置步骤

1. 用文本编辑器打开 `backend/.env`。如果没有该文件，从 `backend/.env.example` 复制一份。
2. 填写以下配置：

```ini
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_API_KEY=你的密钥
LLM_MODEL=deepseek-chat
```

3. 保存文件。
4. 下一次运行工作流时自动生效，无需重启服务。
5. 调试抽屉显示 `LIVE MODEL` 即表示已识别到密钥。页面打开期间修改 `.env` 后，模式标签需要刷新页面才会更新。

### 9.2 常用服务示例

| 服务 | Base URL | 模型示例 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |

### 9.3 配置优先级

- 节点中填写的“模型名称”优先。
- 节点未填写模型名时，使用 `.env` 中的 `LLM_MODEL`。
- 接口地址与密钥只从后端 `.env` 读取，前端不会也不应传入密钥。

如果出现“密钥无效”“接口连接失败”或“模型名称和账户额度”等提示，请检查密钥、Base URL、模型名和账户余额。

## 十、生产模式运行

开发模式会同时启动两个服务。若只需要运行一个服务，可先构建前端：

```bat
cd frontend
npm run build
```

随后只启动后端：

```bat
cd backend
```

FastAPI 会自动托管 `frontend/dist`，此时访问 <http://127.0.0.1:8010> 即可使用完整应用。修改前端代码后需要重新执行 `npm run build`。

## 十二、数据、隐私与清理

| 数据 | 保存位置 | 说明 |
| --- | --- | --- |
| 当前工作流 | `backend/data/studio.db` | 保存节点、连线、名称与配置 |
| 生成音频 | `backend/data/audio/*.mp3` | 服务启动时清理超过 24 小时的文件 |
| 调试草稿 | 浏览器 `localStorage` | 键名 `paiagent2.debug-input` |
| 大模型密钥 | `backend/.env` | 不写入数据库，不进入前端 |
| 运行状态 | 浏览器内存 | 刷新后清空，不写入工作流文档 |

网络与隐私：

- 未配置大模型密钥时，口播稿在本地整理。
- 配置密钥后，测试文字会发送到你配置的大模型服务。
- 无论是否配置大模型，合成音频时上游文本都会发送到 Edge TTS 在线服务。
- 如需完全离线使用，必须替换为本地大模型与本地 TTS 实现。

备份与清理：

- 备份工作流可复制 `backend/data/studio.db`。
- 生成音频属于临时产物，可按需删除 `backend/data/audio` 下的文件。
- 不要将 `backend/.env` 提交到代码仓库。

## 十三、常见问题

| 问题 | 可能原因与处理 |
| --- | --- |
| 顶栏显示“引擎离线” | 后端未启动或端口不一致。确认 `http://127.0.0.1:8010/api/health` 可访问，重启后端 |
| 语音合成失败 | Edge TTS 需要外网。检查网络与代理后重试；文本过长也会导致失败 |
| 没有生成真实模型文案 | `.env` 中的 `LLM_API_KEY` 未填写或未生效。确认模式标签为 `LIVE MODEL` |
| 运行后提示“未接入主链路” | 有节点未连接进“用户输入 → 结束”。补全连线或删除孤立节点 |
| 运行后提示“存在循环连线” | 连线形成了环。删除造成循环的连线，DAG 不允许循环依赖 |
| 无法连接两个节点 | 检查是否从结束节点继续连线、是否连向用户输入、是否自连或重复 |
| 提示口播稿超过 3000 字 | 缩短上游文本，或调整提示词控制输出长度 |
| 请求返回 422 | 请求参数不合法，常见于调试文字为空或超过 4000 字。刷新页面后重新输入 |
| 音频无法播放 | 浏览器拦截自动播放时再点一次播放；仍失败则检查音频接口和后端日志 |
| 音频一段时间后消失 | 音频是临时文件，服务启动时会清理超过 24 小时的文件，请重新生成或及时下载 |
| 停止后后台还会继续生成吗 | 前端会立即停止等待，但服务端已发出的外部请求（例如语音合成）可能短暂继续并完成；稍后重新运行即可 |
| 刷新后修改丢失 | 只有点击“保存”后的工作流会恢复，未保存更改会丢失 |
| 保存失败 | 后端离线或数据库目录不可写。检查服务状态与 `backend/data` 权限 |
| 端口被占用 | 修改端口时需同步调整 `frontend/vite.config.ts` 的端口与代理、`scripts/start-backend.bat`，并更新后端 CORS 来源与 `start.bat` 打开的地址 |
| 提示缺少 Node.js 或 Python | 安装 Node.js 20+ 与 Python 3.12+，然后重新执行 `setup.bat` |

CORS 默认来源在 `backend/app/config.py` 中定义，也可在启动后端前设置环境变量 `FRONTEND_ORIGINS` 扩展（多个地址用逗号分隔）；该变量需要在服务启动前生效。

## 十四、已知限制

1. 当前只维护一份工作流，没有工作流列表、版本管理或发布功能。
2. 没有用户体系与权限控制，适合本地或可信内网使用，不建议直接暴露到公网。
3. Edge TTS 依赖外网，离线环境无法合成音频。
4. 执行器按拓扑顺序串行执行节点，分支不会并行运行。
5. 停止按钮只中止前端请求，不能保证撤回服务端已经发出的外部调用。
6. 端到端测试脚本未纳入常驻 CI，升级依赖后建议手动执行一次完整链路。
